# 🤖 XAgent – AI Coding Agent

**XAgent** is an autonomous AI coding agent designed to safely understand, modify, run, observe, and improve software projects directly from the browser. It features a sandboxed environment, real-time code editing, and intelligent problem-solving workflows.

---

## 🧠 Key Features 👇

* 🔐 Authentication
* 🔗 Connect GitHub repositories
* 🧱 Isolated sandbox execution environment
* ⚡ Real-time streaming responses
* 📝 File read, write, and edit tools
* 💻 Bash command tools
* 🌿 Git tools (status, commit, push)
* 🔀 Create pull requests
* 🧠 AI Models
* 🚀 Built with MERN Stack (MongoDB, Express, React, Node.js)
* ☁️ Deployment

---

## 🏗️ Tech Stack

* Node.js (Backend API + AI orchestration)
* Express.js (Server framework)
* MongoDB (Database)
* React (Frontend UI)
* Upstash Box (Isolated sandbox execution)
* GitHub API / Git integration
* LLM models (DeepSeek, Anthropic, OpenAI compatible)
